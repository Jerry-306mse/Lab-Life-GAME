# Lab-Life-GAME
An open-source research lab simulation game
Initial public release of Lab Life, a research laboratory simulation and management game.

This release includes:
- Core laboratory simulation and management gameplay.
- Student recruitment and attribute management.
- Research projects, academic journals, and publication systems.
- Research funding and laboratory equipment management.
- Interactive game scenes and supporting activities.
- A visual content editor for managing students, journals, items, and other game data.
- A multi-file development structure for future community contributions.

The project is being made public to encourage collaboration, feedback, bug reports, and community-driven improvements.

This is an early development version. Some features may still require testing, optimization, and further refinement.

Contributions and suggestions are welcome!
